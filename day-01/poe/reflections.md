# My Reflection

**1. Orientation**

During orientation, I learned what the course is about and what I was expected to do. I was introduced to programming and how the course will work. At first, I was not sure what to expect, but I was interested in learning new things.

**2. Thonny**

I learned how to use Thonny to write and run Python code. At first, it was not easy because some things were new to me. Sometimes I made mistakes, but I learned that I must check my code and try again. The more I practised, the more I understood how Thonny works.

**3. Git**

I learned about Git and how to save my programming work. I also learned that Git helps us keep track of changes in our code. It was something new to me, but I started understanding why programmers use it.

**4. Planning to Code**

I learned that before I start coding, I must first understand the problem. I must plan what I want the program to do and think about the steps. I also learned that planning makes coding easier because I know where to start and what to do next.

**5. Marks Analyser**

When we started building the Marks Analyser, I learned how to use Python to work with student marks. I learned how to capture marks, calculate results and display information. I enjoyed this activity because I could see how the things we learned can be used to create a real program.

**6. Building the Marks Analyser in Six Steps**

Building the Marks Analyser in six steps helped me understand that I do not have to do everything at once. I can break the program into smaller steps and complete one step at a time. Sometimes I struggled to understand what to do, but I kept trying until I got it right. I was happy to see the program working after completing the steps.

### Overall Reflection

Coming from a rural area, learning programming is not something I was used to. English is also a challenge for me because it is not my first language. Sometimes I need more time to understand the instructions, especially when there are new computer words. But I am trying my best to learn. This course has helped me understand more about programming, and I am becoming more confident. I have learned that I must be patient, practise and not give up when my code is not working. I still have a lot to learn, but I am happy with what I have learned so far.
